# 💰 Meu Negócio

Sistema de gestão financeira desenvolvido para pequenos negócios, com foco em organização, controle de movimentações e visualização de informações financeiras.

## 📌 Sobre o projeto

O **Meu Negócio** surgiu como uma proposta desenvolvida durante meu **TCC do curso Técnico em Administração**.

A ideia inicial do projeto era propor uma solução para auxiliar pequenos negócios na organização e no acompanhamento de suas informações financeiras, buscando tornar o controle das movimentações mais simples e acessível.

Posteriormente, o projeto foi desenvolvido como uma aplicação web, utilizando tecnologias de desenvolvimento frontend, transformando a proposta inicial do TCC em um projeto prático para meu portfólio.

Atualmente, a aplicação conta com funcionalidades como cadastro e login de usuários, controle de receitas e despesas, categorias de movimentações, dashboard financeiro e visualização de dados.

> ⚠️ **Importante:** este é um projeto de portfólio/frontend. Os dados são armazenados localmente no navegador por meio de `localStorage` e `sessionStorage`, portanto não deve ser utilizado para armazenar informações financeiras reais.

---

## 🚀 Funcionalidades

- 🔐 Cadastro e login de usuários
- 👤 Exibição das informações do usuário
- 💰 Controle de receitas e despesas
- 📊 Dashboard financeiro
- 📈 Visualização de dados através de gráficos
- 🏷️ Organização de transações por categorias
- 🔎 Filtro de transações
- ➕ Adição de novas movimentações
- 🗑️ Exclusão de transações
- ⚙️ Atualização de informações do usuário
- 🚪 Logout
- 💾 Persistência de dados no navegador
